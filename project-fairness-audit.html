A Fairness Audit Playbook for AI Systems

The Problem

Organisations deploying automated decision-making systems face increasing regulatory and reputational pressure to demonstrate fairness. But "conducting a fairness audit" means very different things to different teams. Some run a single demographic parity check on model outputs. Others commission expensive third-party reviews. Most do nothing systematic at all.

The gap this project addresses: a replicable, end-to-end audit methodology that a data team can apply to any classification system using open tools.

The Approach

I developed a step-by-step fairness audit methodology and applied it to real-world automated decision systems. The playbook covers four phases: defining the audit scope and identifying protected attributes; computing group fairness metrics across demographic parity, equalised odds, and predictive parity; applying counterfactual testing to isolate whether protected attributes are driving decisions; and documenting findings in a structured audit report with a risk classification for each identified disparity.

Each phase includes decision trees for selecting the right metric given the use case, and worked examples from hiring, credit, and content moderation systems.

Key Findings

No single fairness metric is sufficient for all contexts. Demographic parity, equalised odds, and predictive parity can conflict with each other, and choosing among them requires an explicit value judgement about which errors are more costly.

Counterfactual testing frequently reveals bias that group-level metrics miss, particularly in cases where protected attributes are correlated with features used in the model.

The audit documentation phase is consistently undervalued: findings without a clear risk classification and remediation path are unlikely to result in action, regardless of technical accuracy.

Impact

The playbook has been published as a practical guide for data teams and AI practitioners. It provides a structured approach that can be adapted to any classification context, from financial services to public sector decision-making. The counterfactual testing methodology in particular addresses a gap in most existing fairness audit frameworks.

What I Learned

Auditing a system for fairness requires being explicit about whose interests the audit is designed to protect. The same model can appear fair or unfair depending on which metric you choose, and that choice is a normative decision, not a technical one. The most important part of any audit is writing down that decision and defending it.
